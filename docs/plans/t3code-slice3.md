## Decisions
1. **Tool names:** `a2ui_rules` (rules tier) and `a2ui_check` (send tier). Both `Readonly`, `Idempotent`, `readsAsCaller`. `a2ui_check` `success` = `Struct({ ok: Boolean, error: optional(String) })`, returned with `Effect.succeed` for both outcomes; `failure` = `OrchestratorMcpFailure` only for infra errors (thread lookup), `failureMode: "return"` as in `toolkits/html`.
2. **Rules text:** `ExpressPromptGenerator([schemaCatalog]).generate()` + one host paragraph teaching `surface("<id>", update=true)` and the `a2ui-action` reply, generated lazily once per process: `A2uiReplyCheck.ts` has no top-level `@a2ui/*` imports; a memoized `loadA2ui()` does `await import(...)` and builds the catalog on the first tool call, so server boot never loads antlr4ng/web_core.
3. **Pointer:** ≤1 KB, exported as `A2UI_POINTER` from `orchestrationInstructions.ts` and interpolated into section 3 (the gate measures the constant, not the section). Same facts as Buzz's `A2UI_POINTER` (prose then a block on its own lines, never a fence, basic catalog only, `update=true` for follow-ups, answers return as an `a2ui-action` message, call `a2ui_rules` before the first form and `a2ui_check` before replying). No backticks-fence string.
4. **Schema catalog on the server:** `new Catalog(v1 basic id, "1.0", BASIC_COMPONENTS, BASIC_FUNCTIONS, BasicCatalogThemeSchema)` from `@a2ui/web_core/catalogs/basic/v1` (server has no lit/DOM constraint). Same id and component set as `apps/web` `t3BasicCatalog`, asserted by a test.
5. **Check algorithm** (port of Buzz `checkA2uiReply`): segments of the draft via `splitA2uiSegments` (`@t3tools/shared/a2uiMessage`); none → "No <a2ui> block"; any unclosed → error; replay `a2uiThreadBlocks(earlier assistant messages)` then the draft's blocks (synthetic id `__a2ui_draft__`, not Buzz's `"new"`) through one `RendererState`, using the same per-block default surface id as the web store (`a2ui-${key}`); first failure wins.
6. **Ownership:** t3code runs one agent per thread, so the `ownership` capability is not claimed (1 case skips). `authorKind` is claimed: the replay reads assistant messages only.
7. **Deps:** `apps/server` gains exact `@a2ui/agent@0.2.1` + `@a2ui/web_core@0.16.1` (no `@a2ui/react`). `web_core` keeps its own zod 3 (pnpm nests it under server's zod 4; verify `pnpm why zod` and the bundle).
