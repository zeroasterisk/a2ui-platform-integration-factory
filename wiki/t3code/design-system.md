# Web: tokens and theme

- Tailwind v4, single global stylesheet `apps/web/src/index.css` (2571 lines). Layers declared at
  `index.css:2` (`theme, base, clerk, components, utilities`); `@import "tailwindcss"` at `:3`.
- Theme-only rules use custom variants `dark`/`light` (`index.css:5-6`), not `.dark` selectors
  (rule: `docs/internals/web-ui.md:22`).
- Raw palette vars (`--primary`, `--card`, `--foreground`, `--muted`, …) are set per mode on
  `:root` (`index.css:91`, light `--primary: oklch(0.488 0.217 264)` at `:1130`, dark at `:1199`)
  and overridden by user/custom themes through `--app-theme-*` vars (`index.css:1330-1350`,
  e.g. `--primary: var(--app-theme-message-action)`).
- `@theme inline` (`index.css:177`) maps them to Tailwind colors: `--color-primary`,
  `--color-card`, `--color-muted-foreground`, `--color-message`, `--color-sidebar-*`, radii
  `--radius-sm..3xl` derived from `--radius` (`index.css:255-295`).
- Layout tokens: `--control-radius: 0.5rem` (`:103`), `--chat-content-max-width: 46rem` (`:131`).
- Theme machinery: `apps/web/src/themePalette.ts`, `appearanceContrast.ts`, `appearanceFonts.ts`,
  `vscodeThemeImport.ts`; settings UI `components/settings/AppearanceSettingsPanel.tsx`.
  User-facing: custom themes + VS Code import (`docs/user/appearance.md`).
- Sandboxed visuals get the theme pushed in: `apps/web/src/hooks/useHtmlRenderTheme.ts:30` and
  `htmlRenderTheme()` in `packages/shared/src/htmlRender.ts:175`. A native A2UI renderer would not
  need this — it inherits CSS vars directly.

# Web: primitives (`apps/web/src/components/ui`)

~50 files, all built on `@base-ui/react` + `class-variance-authority` + `cn` (`~/lib/utils`):
`button.tsx`, `input.tsx`, `textarea.tsx`, `checkbox.tsx`, `switch.tsx`, `radio-group.tsx`,
`select.tsx`, `combobox.tsx`, `autocomplete.tsx`, `number-field.tsx`, `toggle.tsx`, `toggle-group.tsx`, `badge.tsx`, `alert.tsx`, `table.tsx`,
`separator.tsx`, `skeleton.tsx`, `spinner.tsx`, `tooltip.tsx`, `popover.tsx`, `dialog.tsx`,
`sheet.tsx`, `menu.tsx`, `calendar.tsx`, `color-picker.tsx`, `empty.tsx`, `label.tsx`,
`group.tsx`, `input-group.tsx`, `wizard.tsx`, `collapsible.tsx`, `kbd.tsx`, `toast.tsx`.
There is no `tabs.tsx` or `slider.tsx` primitive.

- Example: `button.tsx:1-3` imports `mergeProps`/`useRender` from base-ui and `cva`; variants at
  `button.tsx:8-70` (`default`, `secondary`, `outline`, `ghost`, `destructive`, `link`, …) and
  sizes (`xs`, `sm`, `default`, `lg`, `icon*`).
- **Hard rule** (`AGENTS.md:197`): ui exports own their look — pick `variant`/`size`, never restyle
  with `className`; layout classes go on the parent. Enforced by `shadcn/no-restyle`
  (`vite.config.ts:539`, plugin registered `vite.config.ts:211-213`).
- Don't style raw `<button>/<input>/<select>` to mimic a primitive (`docs/internals/web-ui.md:8-10`).
- No `style={{}}` for static values; Tailwind classes in the owning component (`web-ui.md:14-21`).
- Composition reference = `ComposerBanner` slots (`web-ui.md:24-39`).
- React Compiler must compile every file; `useMemo`/`useCallback` banned by
  `t3code/no-manual-memo` (`web-ui.md:57-76`).

**Implication for A2UI:** an A2UI basic-catalog → t3code mapping is a thin table
(`Button→Button variant`, `TextField→Input/Textarea`, `CheckBox→Checkbox`, `ChoicePicker→Select /
RadioGroup / ToggleGroup`, `DateTimeInput→Calendar`, `Divider→Separator`, `Card→div with card
tokens`, `Modal→Dialog`, `Tabs`→ToggleGroup or new variant). Anything without a primitive must be a
feature-local component, not a new `components/ui` file, unless generic (`AGENTS.md:197`).

# Mobile (`apps/mobile`, Expo 58 + React Native)

- Styling: **Uniwind** (Tailwind v4 for RN), `apps/mobile/package.json:140` (`uniwind 1.13.0`),
  `tailwindcss ^4` dev dep. `apps/mobile/global.css:1-3` imports tailwind, uniwind and
  `generated-uniwind-themes.css` (1960 lines, generated by `scripts/generate-uniwind-themes.mts`,
  vars like `--color-screen`). Typography scale in `global.css:14-38` mirrors `src/lib/typography.ts`.
- Mobile has its own themes, not environment themes (`docs/user/appearance.md`, mobile section);
  prefs in `apps/mobile/src/lib/appearancePreferences.ts`.
- Primitives `apps/mobile/src/components/ui/`: `Button.tsx` (tones `primary|secondary|danger|text|
  contrast` → classes `bg-primary text-primary-foreground` etc., `Button.tsx:20-26`), `Chip`,
  `ListRow`, `ListToggleRow`, `NativeSwitch`, `SegmentedControl`, `NumberField`, `SliderRow`,
  `Dialog`, `Sheet`, `Menu`, `Notice`, `ErrorBanner`, `EmptyState`, `Progress`, `AppText`,
  `SearchField`, many with `.android.tsx`/`.ios.tsx` splits.
- Markdown on mobile = `react-native-enriched-markdown` (patched tgz, `package.json:124`),
  wrapped by `apps/mobile/src/native/EnrichedMarkdownText.tsx`.
