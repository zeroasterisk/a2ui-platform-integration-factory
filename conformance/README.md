# Conformance

Shared fixtures every host integration must pass. Data only: hosts copy or replay them, never import them (principles §1, §4).

## Groups (from `docs/reviews/argon-phase5b-close.md` §5)

| Group | Dir | State |
|---|---|---|
| Wire + sentinel lexer (`splitA2uiSegments`, `a2uiActionMessage`, `a2uiActionSummary`) incl. trust cases: streaming, fenced/prose, size, action-payload spoof | `wire/` | ✅ 23 checks |

| Off-catalog component blocked with source disclosure; person-authored block → plain text | `trust/` | ⏳ |
| Visual gates (360/412, 150% text, field/card contrast, inert + dim) | `visual/` | ⏳ |

## wire/

- `lexer.json`: message text → expected segments (`kind`, `offset`, `source`, `closed`). `group` tags trust cases.
- `action.json`: action event → expected action message / summary text.
- `run.mjs`: replays both against a host module that exports the lexer API.

```bash
node --experimental-strip-types --no-warnings conformance/wire/run.mjs <host>/a2uiMessage.ts
```

## thread/

- `thread.json` (generated by `gen.py`, edit the generator): 13 cases. Each is a step list: `sender` (`ok` / `hold` / `fail`), `sync` (blocks `{key, source, authorId?}`), `dispatch` (fire the fixture event on a surface), `release`, `mark`, `expect` (results, live surfaces per block, surface texts, send state, send count/authors, version/identity since `mark`).
- `requires: ["ownership"]` marks per-author cases (multi-agent hosts). A single-agent host declares no capability and those cases skip.
- `replay.mjs`: dependency-free replay; the host's own test runner imports it and passes `{ createStore, capabilities }`, so `@a2ui/*` and host aliases resolve as in production. Throwaway host test:

```ts
const { replayThread } = await import(".../conformance/thread/replay.mjs");
const r = await replayThread(fixture, { createStore: () => new A2uiThreadStore(catalog), capabilities: ["ownership"] });
expect(r.fail).toEqual([]);
```
