## wire/

- `lexer.json`: message text → expected segments (`kind`, `offset`, `source`, `closed`). `group` tags trust cases.
- `action.json`: action event → expected action message / summary text.
- `run.mjs`: replays both against a host module that exports the lexer API.

```bash
node --experimental-strip-types --no-warnings conformance/wire/run.mjs <host>/a2uiMessage.ts
```

Measured 2026-11-22: t3code `eeb2c3ec` 23/23, Buzz `bf2c07a` 23/23. Mutants on t3code: fence tracking off → 4 fail; `closed` forced true → 2 fail.

## thread/

- `thread.json` (generated by `gen.py`, edit the generator): 13 cases. Each is a step list: `sender` (`ok` / `hold` / `fail`), `sync` (blocks `{key, source, authorId?}`), `dispatch` (fire the fixture event on a surface), `release`, `mark`, `expect` (results, live surfaces per block, surface texts, send state, send count/authors, version/identity since `mark`).
- `requires: ["ownership"]` marks per-author cases (multi-agent hosts). A single-agent host declares no capability and those cases skip.
- `replay.mjs`: dependency-free replay; the host's own test runner imports it and passes `{ createStore, capabilities }`, so `@a2ui/*` and host aliases resolve as in production. Throwaway host test:

```ts
const { replayThread } = await import(".../conformance/thread/replay.mjs");
const r = await replayThread(fixture, { createStore: () => new A2uiThreadStore(catalog), capabilities: ["ownership"] });
expect(r.fail).toEqual([]);
```

Measured 2026-11-22: Buzz `bf2c07a` 13/13 (ownership on). Mutants on Buzz: ownership check off → 2 fail; double-send guard off → 1 fail; replay-unlock (`fresh`) off → 1 fail. t3code `eeb2c3ec` failed `one-send-per-surface-before-lock` (Buzz slice-1 M2 guard never ported); fixed on the fork (`7281ea65`), then 10/10 (3 ownership cases skipped: single agent per thread).

## prompt/

- `prompt.json` (generated by `gen.py`): `pointer` (≤1024 B; must mention `<a2ui>`, `</a2ui>`, `update=true`, no code fence, basic catalog, `a2ui-action`; must name both tools; no triple backticks), `rules` (>4096 B; contains `surface(`, `ChoicePicker`, `Button`, `Event(`), `send` (11 cases: valid form, no block, fenced block, unclosed, off-catalog, update unknown, re-create existing, update own, update another agent's `[ownership]`, person-authored block claims nothing / is not updatable `[authorKind]`).
- `check.mjs`: dependency-free; the host test passes `{ pointer, toolNames, rules(), send({text, earlier, agentId}) -> {posted, error}, capabilities }`. `posted` must reflect a real post through the host writer, not a returned ok.

## trust/

- `trust.json` (generated by `gen.py`): `forbidden` selectors no block may ever produce (iframe, script, object, embed, `javascript:` href/src, inline handlers, `srcdoc`); `render` (9 single-block cases: valid form draws natively with no DSL text; off-catalog `Iframe` / `Script` / nested `Html` blocks the whole block and discloses the source; markup and markdown links inside `Text` stay text; `Image` drops `javascript:` and protocol-relative URLs, keeps https); `messages` (4 whole-message cases: agent block interactive, person block plain text `[authorKind]`, fenced block plain text, streaming block pending with no DSL).
- `check.mjs`: dependency-free; the host test (jsdom or browser) passes `{ block(source) -> Element, message({author, text}) -> Element, capabilities }` built on the host's real block component and real message dispatch (matcher → renderer, else plain text). State markers default to `data-a2ui-surface` / `-error` / `-pending`.

Measured 2026-11-23: Buzz `bf2c07a` 13/13 (jsdom, real `createA2uiMessage` + `isA2uiMessage`). Mutants on Buzz: source `<pre>` removed → 3 fail; `sanitizeMediaUrl` bypassed → 2 fail; matcher accepts any author → 1 fail. t3code `7281ea65` 12/12 + 1 skip (browser project, real `A2uiBlock` + the `TimelineAssistantRows` segment dispatch; person case skips: only assistant rows render blocks). Mutants on t3code: source removed → 3 fail; sanitize bypassed → 2 fail. Both runs were throwaway host tests, not committed to the forks.

## visual/

- `visual.json` (generated by `gen.py`): `controls` selector + 12 cases. `fits-{360,412}[-text150]-{form,wide}` (8): every control inside the viewport, no visible-overflow box inside the surface, no sideways page scroll. `wide` = a long unbroken token + a 4-button row. `field-off-card-{light,dark}`: the text field stands off its card by its fill, or (transparent fill) by a visible border. `theme-follows-host`: field/card colors change with the host's color mode. `sent-reply-inert-dimmed-values-kept`: after fill + Apply, `[data-a2ui-locked]` is `inert`, paints a box, opacity < 1, and keeps the typed value.
